# Career Copilot

Career Copilot is a web application designed to help job seekers understand
how well their skills match a job opportunity.

## Why I am building this

Finding a job can be difficult when you are not sure whether your current
skills match what an employer is looking for.

This project aims to make that process easier by comparing a candidate's
skills with a job description and providing practical feedback.

## Planned features

- Candidate profile
- Job description analysis
- Skill matching that recognises common spellings such as JS, ReactJS, PostgreSQL and REST APIs
- Skill gap recommendations
- Interview preparation
- AI-powered career suggestions
